# Assignment 4：优先队列

## 作业概览

本作业围绕动态内存、抽象数据类型和优先队列展开。核心目标是分别使用“有序动态数组”和“二叉最小堆”实现同一套优先队列接口，再利用优先队列完成排序与流式 Top-K 查询，并通过功能测试和计时测试比较不同实现的性能。

队列中的元素类型为 `DataPoint`，包含名称和整数优先级。优先级数值越小，元素越靠近队首，因此 `peek` 和 `dequeue` 都处理当前优先级最小的元素。

## 主要内容

### 1. 动态内存热身

`src/warmup.cpp` 用测试示例练习动态数组的分配、访问和释放，重点区分 `delete` 与 `delete[]`，为后续自行管理优先队列的底层数组做准备。

### 2. 有序数组优先队列

`PQSortedArray` 使用动态数组保存元素，并始终让数组按优先级降序排列：

- `enqueue` 查找插入位置并移动元素，复杂度为 O(n)。
- `peek` 和 `dequeue` 直接访问数组末尾的最小优先级元素，复杂度为 O(1)。
- 数组满时将容量扩大为原来的两倍。
- `validateInternalState` 检查容量范围和排序不变量。

### 3. 二叉堆优先队列

`PQHeap` 使用数组表示完全二叉树，并维护最小堆性质：每个父节点的优先级都不大于其孩子。

- `enqueue` 将元素放到数组末尾，再通过 `bubbleUp` 上浮，复杂度为 O(log n)。
- `dequeue` 用末尾元素替换堆顶，再通过 `bubbleDown` 下沉，复杂度为 O(log n)。
- `peek`、`size` 和 `isEmpty` 的复杂度均为 O(1)。
- 父子节点下标关系为：父节点 `(i - 1) / 2`，左孩子 `2i + 1`，右孩子 `2i + 2`。

### 4. 优先队列应用

`src/pqclient.cpp` 包含两个客户端算法：

- `pqSort`：将所有元素加入最小堆后依次取出，得到按优先级升序排列的向量。
- `topK`：扫描输入流时只维护最多 k 个候选元素，最终返回优先级最高的 k 个数据点并按降序排列。目标复杂度为 O(n log k)，额外空间为 O(k)。

### 5. 测试与性能分析

各实现文件中包含 Stanford `SimpleTest` 测试，覆盖空队列、重复优先级、负优先级、交错入队出队、随机数据、扩容和压力测试。计时测试用于观察有序数组与堆在数据规模增长时的复杂度差异。

## 调试重点

- 动态数组扩容后要释放旧数组，并更新指针和容量。
- 空队列执行 `peek` 或 `dequeue` 时应调用 `error`。
- 数组实现必须保持降序排列；堆实现必须保持父节点不大于孩子。
- 上浮、下沉时要统一使用同一个孩子下标变量，避免交换错误。
- `topK` 只应保留 k 个候选元素，不能把整个输入流全部存入内存。

项目可通过根目录下的 `PQueue.pro` 使用 Qt Creator/qmake 构建，并通过程序中的 SimpleTest 界面运行测试。
